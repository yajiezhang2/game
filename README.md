# 公主丛林冒险：拯救王子

一个原生 HTML、CSS、JavaScript 与 Canvas 2D 制作的横版平台跳跃小游戏，无第三方依赖。

## 运行

直接在浏览器中打开 `jungle-game-v2.html` 即可游玩。也可以用 VS Code 打开项目文件夹，并通过 Live Server 运行。

## 操作

- 左右方向键移动，空格键跳跃；也支持 A/D、W 键。
- 手机或窄屏设备可使用画面下方的触屏按钮。
- 收集宝石、躲开荆棘并抵达右侧终点救出王子。
- 碰到荆棘会扣除 1 颗宝石并回到起点或营地检查点。
- 点击 ↻ 重新开始。

## 文件

- `jungle-game-v2.html`：游戏、样式与脚本集成的单文件主程序。
- `README.md`：项目说明。
